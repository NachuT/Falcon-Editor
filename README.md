# Falcon
_Transforming our world with the power of FPGA and Cloud._
![Screenshot 2025-11-08 at 10 06 31 AM](https://github.com/user-attachments/assets/015155d9-0f67-4b11-992b-5c83ad6695f3)

## Inspiration
- FPGAs have been much faster than any form of normal CPU compution but the code that it requires is complex and time consuming to develop
- Cloud Computing allows for more and better accesibility to applications increasing userbases
- We wanted to create an application that allows more than just the top companies to utilize FPGA and Cloud technology to significantly boost their projects
## How this works
- We have an app and website to download an editor as well as view your Cloud dashboard with all of the stats and functions you need to deploy
- We created our own IDE specifically to code in Verilog with FPGAs
- This editor has all of the functions such as syntax checking, terminal, file management system, as well as keyboard shorcuts too
- Furthermore, this editor also has AI built in to make th process of development even easier and more expedited
- The python cloud computing code works by connecting a server.py file to a worker.py.
- The cloud computing code also has two advanced algorithms a Binary search algorithm and a Quicksort algorithm created manually.
- We also used APIO, as well as a complex FPGA simulation program to allow programs to run on devices such as ESP32's with a speed closer to FPGA.
- Lastly, we have a bitstream generator to upload this code to both FPGAs and other miscallaneous devices.
## How to run
- Clone the repository
- Run npm run dev, then npm run make
- Finally, open the created desktop app file
